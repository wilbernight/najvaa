# نجوا — بسته‌ی کامل نصب

این پوشه همه‌ی کدهای چت نجوا و پنل مدیریت را دارد، به‌اضافه‌ی `install.sh` که روی یک سرور **دبیان ۱۲ یا ۱۳** همه‌چیز را خودکار نصب می‌کند: همان کارهایی که روی سرور فعلی انجام شد، از جمله DNS و تنظیمات کلادفلر.

## محتوای بسته

| مسیر | چیست |
|---|---|
| `install.sh` | نصب‌کننده‌ی تعاملی (سؤال می‌پرسد، بعد همه‌چیز را خودش انجام می‌دهد) |
| `chat/public/` | خود سایت چت (app.js، فیلتر صدای زنانه، فونت، …) |
| `chat/server/relay.js` | رله‌ی «کور» که فقط متن رمزشده می‌بیند و نگه می‌دارد |
| `chat/voicefx-src/` | سورس دو موتور تغییر صدا و اسکریپت ساخت `voicefx-worklet.js` |
| `system/najva-ddns.py` | به‌روزرسانی خودکار IP در DNS کلادفلر (IPv6 و/یا IPv4) |
| `panel/` | پنل مدیریت (Laravel + Nova) آماده‌ی اجرا، بدون هیچ رمز یا داده‌ای |

هیچ رمز، توکن، گواهی یا داده‌ی چتی داخل این بسته نیست؛ نصب‌کننده همه را روی سرور جدید می‌سازد.

## پیش از نصب

1. یک سرور دبیان ۱۲ یا ۱۳ با دسترسی root.
2. دامنه را به کلادفلر اضافه کنید و nameserverهای ثبت‌کننده‌ی دامنه را روی دو nameserver کلادفلر بگذارید.
3. در کلادفلر یک **API Token** بسازید (My Profile ← API Tokens ← Create Token ← Create Custom Token) با این دسترسی‌ها:

   | بخش | دسترسی | سطح | برای |
   |---|---|---|---|
   | Zone | Zone | Read | پیدا کردن دامنه |
   | Zone | DNS | Edit | ساخت رکوردها و به‌روزرسانی خودکار IP |
   | Zone | Zone Settings | Edit | SSL سخت‌گیرانه، HTTPS اجباری، TLS 1.2 به بالا |
   | Zone | SSL and Certificates | Edit | ساخت گواهی Origin پانزده‌ساله |
   | Account | Access: Apps and Policies | Edit | محافظت پنل با کد یک‌بارمصرف ایمیلی |
   | Account | Access: Organizations, Identity Providers, and Groups | Edit | روشن کردن ورود با کد ایمیلی |
   | Account | Calls (Realtime) | Edit | (اختیاری) ساخت خودکار کلید TURN برای تماس |

   در Zone Resources دامنه‌ی خودتان و در Account Resources حساب خودتان را انتخاب کنید.
4. (برای پنل) اگر Zero Trust کلادفلر را هنوز فعال نکرده‌اید، نصب‌کننده خودش می‌گوید که one.dash.cloudflare.com را باز کنید، یک نام تیم و پلن رایگان انتخاب کنید و برگردید.

## نصب

از کامپیوتر خودتان بسته را به سرور بفرستید (فایل `najva-package.tar.gz` کنار همین پوشه است):

```bash
scp najva-package.tar.gz root@SERVER:/root/
```

بعد روی سرور:

```bash
cd /root && tar -xzf najva-package.tar.gz && bash najva-package/install.sh
```

## سؤال‌هایی که نصب‌کننده می‌پرسد

1. **دامنه‌ی چت**، مثلاً `example.com`. چت روی خود دامنه باز می‌شود و `www` به آن هدایت می‌شود.
2. **توکن کلادفلر.** موقع تایپ دیده نمی‌شود؛ در اجراهای بعدی با زدن Enter همان توکن قبلی می‌ماند.
3. **آدرس‌های سرور.** IPv6 و IPv4 را خودش پیدا می‌کند و می‌پرسد کدام منتشر شود. پشت CGNAT (مثل استارلینک) فقط IPv6 کار می‌کند.
4. **تماس صوتی.** ساخت خودکار کلید TURN کلادفلر، یا وارد کردن دستی آن.
5. **فضای تاریخچه.** سقف حجم (پیش‌فرض ۵۰ گیگ) و مدت نگه‌داری (پیش‌فرض ۹۰ روز).
6. **پنل مدیریت.** نصب بشود یا نه، آدرسش (پیش‌فرض `mod.دامنه`)، ایمیل ادمین و (اختیاری) لایسنس Nova.

بعد یک خلاصه نشان می‌دهد و با تأیید شما شروع می‌کند.

## کارهایی که خودکار انجام می‌شود

- نصب nginx، Node.js و (برای پنل) PHP.
- نصب سایت و رله؛ رله با کاربر موقت سیستمی و محدودیت‌های امنیتی systemd اجرا می‌شود.
- ساخت گواهی Origin کلادفلر (۱۵ ساله) با کلیدی که فقط روی همین سرور ساخته می‌شود.
- nginx فقط به آدرس‌های کلادفلر جواب می‌دهد، پس IP سرور پنهان می‌ماند. لاگ دسترسی چت خاموش است.
- رکوردهای DNS (پروکسی‌شده) برای دامنه، `www` و پنل. اگر رکوردی از قبل به جای دیگری اشاره کند، قبل از تغییر می‌پرسد.
- تنظیمات دامنه: SSL روی Full (strict)، HTTPS اجباری، حداقل TLS 1.2، TLS 1.3 و WebSocket.
- به‌روزرسانی خودکار IP هر ۵ دقیقه.
- پنل:
  - Cloudflare Access فقط برای ایمیل شما، با کد یک‌بارمصرف.
  - کاربر سیستمی جدا و PHP-FPM اختصاصی.
  - دیتابیس SQLite و زمان‌بند.
  - در پایان، ساخت حساب ادمین (رمز را خودتان وارد می‌کنید).
- بررسی نهایی: سایت از طریق کلادفلر باز می‌شود و پنل پشت Access است.

## بعد از نصب

- **چت:** `https://دامنه`
- **پنل:** `https://mod.دامنه`
  1. ایمیل را وارد کنید و کدی را که کلادفلر می‌فرستد بزنید.
  2. با حساب پنل وارد شوید.
  3. در «حساب من» ورود دومرحله‌ای یا passkey را روشن کنید. تا این کار را نکنید، بقیه‌ی پنل باز نمی‌شود.
- **فراموشی رمز پنل:**

```bash
cd /var/www/mod.DOMAIN && sudo -u najvapanel php artisan najva:password EMAIL
```

## به‌روزرسانی

نسخه‌ی جدید بسته را روی سرور باز کنید و دوباره `bash najva-package/install.sh` را بزنید. جواب‌های قبلی پیش‌فرض می‌شوند (فقط Enter بزنید). رمزها، گواهی، تاریخچه‌ی رمزشده و دیتابیس پنل دست نمی‌خورند.

## جای چیزهای مهم روی سرور

| چیز | مسیر |
|---|---|
| تنظیمات و رمزهای رله | `/etc/najva/relay.env` (فقط root) |
| توکن کلادفلر و تنظیم DDNS | `/etc/najva/cf.env` (فقط root) |
| گواهی Origin | `/etc/ssl/najva/` |
| تاریخچه‌ی رمزشده‌ی چت | `/var/lib/najva` |
| پنل | `/var/www/mod.DOMAIN` (رمزهایش در `.env`) |
| لاگ نصب | `/var/log/najva-install.log` |
| سرویس‌ها | `najva-relay`، `najva-ddns.timer`، `najva-panel-scheduler.timer` |

## ساخت دوباره‌ی فیلتر صدا (فقط اگر سورس آن را تغییر دهید)

```bash
node chat/voicefx-src/build-voicefx.mjs
```

خروجی‌اش `chat/public/voicefx-worklet.js` است (در سورس اصلی هم `node deploy/build-voicefx.mjs`).
